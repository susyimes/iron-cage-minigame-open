# 暴走台球 · 微信小游戏

本目录是微信开发者工具工程根目录，正式 AppID 为 `wx43331b46521a20b7`。客户端与网页版共用 Three.js 场景、八球判罚、物理、卡牌和协议 4，菜单和触控由小游戏 Canvas UI 实现。

## 构建与调试

在 `iron-cage-minigame/` 根目录运行：

```bash
npm install
npm run typecheck
npm run test:minigame
npm run test:online
npm run build:minigame
```

开发者工具导入本目录，编译后应显示首页，可选择单人练习、联机、设置或玩法说明。`game.json` 配置横屏。先执行根目录 `npm run build:minigame` 生成 `js/game-bundle.js`。公开包使用合成环境声，不包含原音乐文件。填写自己的 AppID；联机前将 `client/src/minigame/runtime.ts` 的示例域名改为自己的服务。

`npm run dev` 配合 `npm run dev:server` 可在 `/minigame-preview.html` 检查同一套 Canvas UI、触控和联机流程。该页面仅用于开发，不会打入小游戏包；浏览器验证不能替代微信真机检查。

## 操作

- 台面单指左右拖动瞄准，上下拖动调抬杆；双指拖动转镜头，捏合缩放。
- 按住右下角「蓄力」，松手出杆；滑出按钮取消。拖动瞄准不会自动蓄力。
- 「微调」「抬高／压低」可按住使用，「全桌」切换视角。
- 联机自由球时点台内空位摆白球。单人犯规自动复位白球，其余球保持落点。
- 抽卡时点选三张卡之一；不会自动替玩家选择。
- 回到击球位恢复水平杆；每位玩家的瞄准方向独立。
- 对局菜单提供继续、画质、声音、退出。单人切后台暂停，联机返回前台同步服务器状态。
- 联机结束后双方点「再来一局」在原房间重开并轮换开球，等待确认或对手离开均有提示。

## 联机与上传

服务地址：`wss://your-server.example.invalid/ws`。小游戏后台的 socket 合法域名应包含 `wss://your-server.example.invalid`，工程启用域名校验。输入相同四位字母或数字房间码即可与网页玩家同桌，留空创建随机房间。昵称可选，无需游戏账号。

用开发者工具预览二维码进行真机验收后上传：

```bash
cli upload --project <本目录绝对路径> -v 0.1.4 -d "完善小游戏菜单、触控、选卡和跨端联机体验"
```

开发版上传与提交审核是两个步骤。后台版本管理选择对应开发版本后填写审核说明并提交；以后台审核状态为准。

## 画质与兼容

高画质、均衡、流畅均为玩家手动选择，即时生效并记住本机设置，不动态降档。保留原生 Canvas 尺寸访问器，保证实际绘制缓冲区与画质分辨率一致；UI 贴图只在可见信息改变时更新，并避让刘海、系统底部及微信胶囊按钮。

音效通过 `wx.createWebAudioContext()` 播放，不支持该 API 时静音降级。手机听感、不同设备帧率和后台 socket 域名配置仍需真机验收。
